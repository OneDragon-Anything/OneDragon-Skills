# 0003. 实现顺序:流程驱动 + 逐画面微循环(非跨画面并行)

- **Status**: accepted
- **Date**: 2026-08-05

## Context

阶段 5(实现)原本只给抽象的"先零件后整体",没给**可操作的实现顺序** —— 写法是"照已建档的画面/流程写 op",但没说**先写哪个画面、按什么节奏推进**。实战(框架负责人 2026-08-05 工作流)更具体:**从玩法入口出发,按游戏实际流程顺序,逐画面闭环** —— 每画面:建档 → 写 op → 测试 → 分支补档循环 → 稳了进下一个。无论"从零摸索玩法"还是"初版设计完开始实现"都用这套。

不这样做的两个常见踩法:
1. **跨画面并行写**(多画面同时半成品):任一画面卡住,定位困难(不知哪个画面的哪步);半成品堆积,集成时一批问题挤一起。
2. **一次性写完再测**:违背探索式主线(分支 / 边缘态实机跑才暴露)—— 一次性写完 = 基于不完备建档硬写,测试时才大批量发现缺口,返工重。

## Decision Drivers

- **可定位**:逐画面闭环 → 卡住时锁在"哪个画面的哪一步",修那步、单跑该 op 验证、再往下;不跨画面纠缠。
- **流程一致**:按游戏实际流程顺序推进(主流程先,分支后由补档循环覆盖),与玩法本身结构对齐,不乱跳。
- **与探索式主线一致**:每画面闭环(建档→op→测试→补分支)= 探索式建档-led 增量在实现阶段的具体化(write-operation ADR-0002);非"规格→实现→交付"。
- **防半成品堆积**:每画面有完成判据才进下一个,不留半成品。

## Considered Options

1. **跨画面并行写**(多画面同时推进):pro 是不阻塞(等某画面测试时写别的);con 是半成品堆积 + 卡住难定位 + 集成爆炸。"不阻塞"由**实现-测试流水线**(后台测 + 趁等待写**下一个 op**,见 build-craft)在**同画面微循环内**覆盖,不是跨画面并行起半成品。
2. **一次性写完再测**:违背探索式(分支实机才暴露),返工重。
3. **流程驱动 + 逐画面微循环**(选中):每画面闭环稳定才推进;卡住可定位;与探索式一致。con 是"等当前画面闭环才能进下一个",由流水线部分缓解,且"稳定才推进"是 feature(防半成品)不是 bug。

## Decision

选 **3**。阶段 5 实现顺序 = **流程驱动 + 逐画面微循环**:

1. **流程驱动**:从玩法**入口**出发,按游戏**实际流程顺序**推进(主流程先,分支后由第 ④ 步补档循环覆盖)。不跨流程乱跳 / 并行起多画面半成品。
2. **逐画面微循环**(每画面闭环):
   - ① **画面建档**(screen_info + 截图 + doc,按 `od-dev-screen-onboarding`)
   - ② **写该画面的 op**(按 `od-dev-write-operation`;op 级探索式微循环见它)
   - ③ **测试**:`run_operation` 单 op 实操 + 代码测试(fixture / unit)
   - ④ **分支补档循环**:遇预料外 → 补建档 + 补分支(按 write-operation 预料外调研 + 本 skill 阶段 8 探索式迭代),循环到该画面稳定
   - ⑤ 该画面闭环 → 进下一个画面
3. **完成判据**:该画面 op **`run_operation` 实测过 + 代码测试过 + 主要分支覆盖**才进下一个。

**职责分工(避免双源)**:op 级技术(微循环 ②③④ 的 how:信息密度 / 调试 / 预料外调研 / 重复建op)single source 在 write-operation;本 skill 只给**跨画面的流程顺序 + 每画面闭环结构**(gameplay 级编排),引用 write-operation 的 op 级方法。

## Consequences

- **正向**:卡住锁定到具体画面(可定位);防半成品堆积;与探索式主线 + 流程结构一致。
- **负向**:"稳定才进下一个"看似串行;由实现-测试流水线(后台测 + 趁等待写**同画面**下一个 op)部分缓解。注意流水线是**同画面内**重叠,不是跨画面并行起半成品(那个被本 ADR 否决)。
- **边界**:op 级技术(怎么写 / 测单个 op)不本 ADR 管(write-operation);探索式迭代的展开(预料外调研细节)在阶段 8。
- **follow-up**:GREEN 验证 —— 实现玩法时是否按流程驱动 + 逐画面闭环推进,而非跨画面并行。
