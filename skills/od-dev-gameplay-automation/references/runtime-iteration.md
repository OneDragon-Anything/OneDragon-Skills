# 运行时迭代深度细则(阶段 8,生命周期视角)

> 本文件是 SKILL.md 阶段 8 的按需读深度细则(**生命周期视角**)。**op 级运行时技术(信息密度 / 调试纪律 / 预料外画面调研 / 运行时不确定性预留日志 / 重复建op)single source 在 `od-dev-write-operation/references/runtime-craft.md`** —— 本文件只给生命周期层的迭代节奏 + 事件 loop 模式,op 级细节去那里读。

## 探索式迭代(为什么阶段 8 是循环,不是善后)

自动化脚本**需求不可完备**:阶段 1 玩法建档只能摸**大概**(主流程 + 主要决策点),玩法的分支 / 子状态 / 边缘情况(随机事件、条件子界面、过渡叠层、各类结算、失败路径…)建档时摸不清,要实机跑到才暴露。故初始方案只是骨架,工作方式是**建档-led 增量**:

**实现(阶段 5)→ 测试(阶段 6)→ 发现未预期状态 / 分支 → 补建档 + 补分支(回阶段 3 画面建档 / 阶段 4 设计 / 阶段 5 实现)→ 再测,循环到稳定。**

**这与肉鸽无必然关系** —— 大部分玩法都有分支(肉鸽只是密)。这是自动化开发的**根本工作方式**,贯穿阶段 5-8,不是某玩法类型的善后阶段。op 级怎么写才适应它(激进拆小 op 单跑定位 / 决策点多 log 多截图 / 预料外画面调研建档 / 调试先读日志 / 重复手动建op)见 `od-dev-write-operation`(探索式主线 + `runtime-craft.md`)。

## §事件长尾 —— 边玩边重构(loop 层)

多分支玩法**事件类型巨多**,没法一次写全。生命周期层(loop)方法论:
- **loop 跑,卡在哪个事件,就读屏 + 加一个 handler op,再跑。**(handler op 怎么写 / 调试见 `od-dev-write-operation`)
- 兜底:任何匹配不到的状态走 fallback(点空白 / ESC),避免死循环。
- 每跑深一点冒新事件是常态,别指望一次覆盖。

## §跨玩法偏离的运行时恢复(loop 调度层)

> §事件长尾的兜底是「任何匹配不到的状态走 fallback(点空白 / ESC)」。但有一类未匹配状态**不能**走这个兜底 —— bot 偏离到了**非目标玩法**:命中画面属于另一个玩法(认知完整,只是非当前在跑的目标)。对它点空白 / ESC 只会让 bot 卡在错玩法里反复转,导航不回目标。须**先分类再分派**。

**loop 的未匹配状态分派,先分类**(每轮读屏未命中目标玩法任何已知画面时):
- 命中画面属于**目标玩法**的未建档事件 / 分支 → 走 §事件长尾(读屏 + 加 handler op + 兜底 fallback)。
- 命中画面属于**非目标玩法**(认得它是玩法 B,但 B 不是当前在跑的玩法 A)→ **不走通用 fallback**,走下方「导航回目标」恢复。

**导航回目标(跨玩法偏离恢复,禁停)**:
1. **退非目标玩法 B**:用 B 画面档案的状态流转出口回到通用枢纽画面(大世界 / 主菜单类)。
2. **进目标玩法 A**:从枢纽走 A 的入口导航路径(查 A 的 screen doc / application 入口节点链)回到 A 的工作画面。
3. **续被打断的工作**:回 A 后接续,不从头重启、不 stall。
- **判据复用 `od-dev-screen-onboarding` 的「跨玩法偏离协议」**(认知完整但非目标 → 导航回,非探索 / 非停);本节补的是 **loop 调度层**怎么把这个恢复落进未匹配状态分派,screen-onboarding 补的是 dev 遇偏离怎么手动导航回 + 把恢复路径建进 screen_info / doc。

**禁止**:stall / 盲重试同一偏离画面 / 走通用 fallback(点空白 ESC 会卡在错玩法)/ 停下等用户指示 —— 偏离是可恢复的运行时状态,导航回目标是 bot 职责,不是中断理由。

**依赖 + 降级**:导航回目标需 B 的出口 + A 的入口路径都已在画面档案建模。**未建档 → 不能自动恢复 → 记日志 + 上报**(别盲循环烧回合);同时触发 `od-dev-screen-onboarding` 补建档(把偏离路径 + 恢复导航建进 screen_info / doc),补全后 loop 后续遇同偏离自动恢复。

**三个「防偏离」别混(不同维度)**:
- **任务进度防偏离**(`progress-tracking.md` §2 防偏离门):**dev 的焦点纪律** —— 别让自主 loop / agent 漂离主线工作(如没打地基就调策略)。
- **dev 跨玩法偏离**(`od-dev-screen-onboarding` ADR-0016):**dev / 建档遇偏离**怎么手动导航回 + 建档防再偏。
- **运行时跨玩法偏离恢复**(本节):**bot loop 自主运行**遇偏离怎么调度恢复。

## §等待时别闲着

bot 跑 / 等加载 / 等刷新期间,**同时做别的事**(自检类似坑 / 预写日志 / 补画面建档 / 沉淀经验),别纯 sleep。
