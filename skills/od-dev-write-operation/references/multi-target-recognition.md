# 多目标特征识别:区域特征一次提取 + 模板集匹配 + 几何过滤 + 得分仲裁

**适用判据(同时满足才用,否则退回逐目标小图匹配)**:①识别区域内有 N 个同类目标且互不重复(每个目标至多出现一次);②每个目标有可靠候选模板(模板集可枚举);③存在辅助定位信号(文本锚点 / 网格几何)可约束每个目标的预期位置。典型:角色 / 物品选择列表、图标阵列、卡面网格——目标数多时,逐个裁小图匹配的开销与裁窗错位风险随目标数线性涨,而区域特征只算一次全模板共享。

## 做法四步(序固定)

1. **区域特征一次提取**:对整个识别区域提一次特征,后续全部模板共用,不按目标预裁小窗(裁窗依赖预设几何,滚动 / 停驻偏移即错位)。
2. **逐模板匹配定位**:每个候选模板对区域特征做一次「比值测试 + 几何一致性验证」;采用带命中位置的匹配结果(单应投影框 / 偏移框),位置由匹配自身给出,不信预设坐标。
3. **几何过滤归属**:命中框与目标预期区域(锚点推算 / 网格槽位)做重叠判定(框中心落入,或 IoU 过门槛)→ 归属到具体目标位;不与任何预期区域重叠的命中丢弃。
4. **冲突仲裁**:同一目标位有多个模板命中 → 按几何验证内点数取最高;最高 / 次高内点比不足歧义门槛 → 诚实返回候选集,不硬猜。

## 网格槽位插值补全(锚点漏采样防线)

槽位构成刚性网格(列距 / 行距在画面内恒定)时,锚点漏读漏的是采样、不是网格——①槽位行带(同行锚点 y 聚类的水平位置)已证实的行,缺列按固定列先验补出;②相邻行带间距为标准行距整数倍时,按网格插值补出中间整行。**只内插不外推**:最高行带之上、最低行带之下不推演——列表边界 / 滚动裁切 / 末尾不满的不确定性留在边缘,由轮廓补充与拒答门槛兜底;插值槽位照常走身份匹配,异常槽被拒答门槛拦下,补错不产错误身份。裁切卡的判别用「可见高度不足」,不用「贴列表边缘」——网格首行的 y 常略超列表区上界,按贴边判会整行误杀(完整首行被当裁切卡丢弃的实机事故形态)。

## 边界与判据

- **模板分辨率下限**:整区域范式下模板面对全区域特征竞争,对低分辨率模板显著更苛刻(特征点过少时几何验证直接失败);同一模板在逐目标小图环境(竞争者少)反而可能通过。两路按模板强弱混用:主路径整区域匹配,无命中目标回退逐目标小图匹配兜底。
- **造型变体失效**:目标渲染与模板存在造型差异(换装 / 形态切换 / 主题滤镜)时,默认模板对该目标零同源,识别失败是预期行为——候选诚实返回;需要识别时补该变体专属模板(与默认模板分库,识别时两库统一仲裁:同位置只渲染其一,天然无冲突)。
- **置信量纲**:几何验证的内点数 / 内点率比单一匹配置信分更可分(真命中与伪命中的内点数差量级;歧义比 = 最高 / 次高内点数比)。
- **耗时**:开销 ≈ 一次区域特征提取 + N 次模板匹配;模板特征变大后可再压(特征索引加速 / 每模板特征按响应截断)。
