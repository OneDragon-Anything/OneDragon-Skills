# ADR-0001:自主推进框架独立成 skill(而非塞进领域 skill 或个人入口文件)

- Status: accepted
- Date: 2026-08-25

## Context

自主推进模式的方法论(开启仪式/编排/纪律/资产组)此前散在三处:个人入口文件(模式本体)、领域 skill(操作事实)、实例工作目录(工作台)。用户提出三落位方案:通用 skill + 领域 skill 增补 + 实例文档。备选落位:

1. 全部进个人入口文件(always-on);
2. 塞进领域 skill(如货币战争 skill);
3. 独立通用 skill(公共仓)+ 领域 skill 只放领域专属事实 + 实例层工作台文档。

## Considered Options

- **全进个人入口文件**:否决——入口文件会越写越肥(方法论细节每次会话都占上下文,但只在自主模式下需要);且无法跨项目复用(换项目要复制)。
- **塞进领域 skill**:否决——受众轴错位:领域 skill 入版本库团队共享,把个人工作模式发布给不需要的协作者(他们可能是指导模式/单次任务);且领域 skill 的职责是领域操作事实,混入个人流程=职责腐蚀。
- **独立通用 skill(选中)**:跨项目复用(公共仓);按需 load(只在自主模式触发);个人入口文件回归「状态行+指针」本职。

## Decision

建独立通用 skill `od-dev-agent-autonomous-mode`(本 skill)。分层落位三问判据(换领域成立吗/换协作者成立吗/该进版本库吗)写进 SKILL.md §4;个人流程编排权归个人入口文件,通过指针引用团队资产与实例资产——个人层=驱动程序,团队层=数据,实例层=工作目录。

## Consequences

- 正:冷启动可复现(读 skill 即获完整启动能力);入口文件瘦身;跨项目零复制。
- 负:skill 与个人入口文件间存在指针依赖(入口文件状态行必须指到本 skill——维护点 +1,由「建资产必建维护回路」判据覆盖)。
- 判例(RCA 论据,不进 SKILL.md 正文):曾因漏受众轴,建议把个人工作模式收编进团队共享的领域 skill,被用户点破后收回。
