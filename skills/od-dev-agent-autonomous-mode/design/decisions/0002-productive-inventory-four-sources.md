# ADR-0002:盘点从「确认循环」改「产出型四来源」+辩护带清单

- Status: accepted
- Date: 2026-08-25

## Context

实战实证:提醒机制在跑但被消费成巡检——「记账:无需派」一行写了几十次,而两个立即可派的事(验证分层/哨兵噪声治本)在待办清单里躺了整个 90 分钟等待窗,被用户两次点破才显形。「空槽显式辩护」退化为惯性辩护(重复上一次内容,未经扫描检验)。

## Considered Options

- **提高提醒频率**:否决——问题不在频率在消费格式;更密=更快刷「无需派」。
- **取消辩护条款**:否决——辩护本身有价值(显式化空闲),病在辩护无检验。
- **产出型格式+辩护带清单(选中)**:盘点必须从四来源(挂账哨兵噪声/文档卫生债/效率损耗/语料缺口)扫出 ≥1 候选件,零候选要留扫描痕迹;「全阻塞」辩护必须附阻塞件名单,列不出=无效。

## Decision

产出型四来源盘点+辩护带清单+「连续两轮同答=窄化信号强制换源」三件套写入 SKILL.md §3 派发纪律。四来源是抽象维度(任何项目都有挂账/债/损耗/缺口),判例留消费方本地。

## Consequences

- 正:等待窗产能从「确认无坏事」变「主动找事」;辩护有了可证伪结构。
- 负:每轮盘点成本↑(四来源扫描)——由「真零候选留痕迹」条款兜底防止形式化空扫。
