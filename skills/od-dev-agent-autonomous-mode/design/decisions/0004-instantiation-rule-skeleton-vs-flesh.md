# ADR-0004:实例化规则——骨架(通用 skill)与血肉(专属资产)的填充契约

- Status: accepted
- Date: 2026-08-25

## Context

通用 skill 只能给骨架(关注面表的结构/提醒网角色/审查清单的层/分层验证的形态),具体细项(格子内容/提醒落点/逐批节/哨兵脚本/快速集命令)全是任务专属的。CW 实战证明:专属资产(实例目录页/审查清单/验证分层协议)是自主推进真正运转的部分,通用 skill 没有它们就是空壳。用户定调:「专属任务有自定的自主推进模式就按它填充细项,没有就按方法论自行思考构建」。

## Considered Options

- **通用 skill 写全细项**:否决——违反规范 4(方法论不写具体例子)+细项随任务千变万化,写死必老化。
- **只在专属文档里写细项,通用 skill 不提**:否决——冷启动时 agent 不知道「要去查专属资产」,容易拿通用骨架硬套(空壳运转)或重新发明。
- **实例化规则进 skill(选中)**:通用 skill 显式写「查专属资产→有则填充→无则自建(建完成为专属资产)」,checklist 第 1 步挂接。

## Decision

§1 增「实例化规则」条款+checklist 第 1 步引用。判据:「通用条款每一条都要能回答『在这任务里它具体是什么/落在哪个文件』」——答不出的条款=未实例化,要么找到专属落点要么自建。

## Consequences

- 正:新任务冷启动有明确动作序(查→填→建);自建的资产自然沉淀为该任务的复用基础。
- 负:首个任务(无专属资产)冷启动成本高(全自建)——由「建完即成为专属资产」的沉淀预期对冲。
