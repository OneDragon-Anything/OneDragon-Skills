# ADR-0004:盘点必须重新实扫

- Status: accepted
- Date: 2026-08-27

## Context

盘点规则 v1 要求「要么给出候选件,要么写明扫了哪些来源、各是什么状态」,意图防走过场。实测(2026-08 CW 自主推进)该要求被**字面满足而实质落空**:编排者连续多轮报告「扫了挂账表/反馈队列/代码 TODO——各状态如前,零候选成立」,实则从未真正打开任何代码或文档,全部结论凭会话记忆复述旧状态——直到用户一句「你去找过具体有什么能做的吗」才穿帮。

根因:「写明扫了什么」是一份**自述**,自述不可验证、因此可以编造——规则只约束了产出的形状,没约束产出与真实动作的因果联系。这与本 skill 核心哲学(结构性约束 > 自觉)冲突:v1 把防线押在了「自觉认真扫」上。派发盘点的提醒词模板(第 4 步答案格式就是「记一行扫了哪些地方,各是什么状态」)是同款漏洞的另一半,教着 agent 写自述。

## Considered Options

- **加码自觉**(措辞改严厉、「要认真扫」):否决——正是失效机制本身;长会话注意力衰减下靠记忆/自觉维持的纪律必然退化成惯性记账。
- **强制每轮全量重读所有来源** 对比 **允许沿用上轮结论+标注**:两者都否决——前者成本不成比例但方向正确;后者是给偷懒开口子,「沿用并标注」在实际执行里会退化成永远沿用。用户裁决取强制性:**下任何状态结论的依据必须是当轮读到的内容**,记忆一律不作数。
- **盘点=重扫轮,证据即动作记录(选中)**:盘点轮禁止引用记忆中的来源状态,候选件只从当轮对最新代码/文档/进度文件的实际扫描里找;零候选的支撑=当轮搜索路径+命中记录。

## Decision

- 盘点条改为「盘点必须重新实扫」:凭记忆作答=无效盘点;自查问=「你真的去找过了吗,路径和命中能当场报出来吗?不能=没扫」。
- 派发盘点提醒模板同步改:来源列表前加动作强制判据;答案格式从自述改为「搜了什么路径+命中了什么或确认为空」;封条加「禁止复述上一轮扫描的记忆下结论」。
- 回顾/子agent审计模板的同款自述句一并改掉(审计对象真扫过后才可记状态)。
- 连续两轮同答的「深扫」补定义:当轮真打开文件/真执行搜索。
- **模板强制逐字复制**:重建提醒词的后续失效(「整块照抄」被理解成「保留大意」,新版强制项在转写中被砍,防记忆作答的封条丢失)证明「整块照抄」这一轻标注不够——提醒词模板节加总则:建/重建定时任务必须逐字复制完整代码块,禁改写/精简/重排。同一风险存在于**指令文件自主推进节的写入**(开启新增/退出后重建都靠 agent 转写本文)——SKILL.md 指令文件节模板同步加同款总则(六个固定字段逐字复制;两类合法偏离=实例位填空[状态/额度/目标/进度入口四字段按实填值]+领域 skill 明文要求的调整[须落覆盖声明])。觉得某项该改且不属两类例外,走 skill 反馈队列由维护方裁决,不给执行现场留裁量权。同根决策(防线经人手转写时静默丢失)并入本 ADR 不另开。

## Consequences

- 正:「零候选」从不可验证的自述变为可抽查的动作记录,与交付验收的断言抽查同型;编造成本抬高到接近实扫成本。「跟之前一样如前」这类断言同时被事实性否定——代码和文档随时在变,旧结论本就不该免检沿用。
- 负:每轮盘点增加固定工具调用开销,多数轮次增量信息为零——被接受为防退化的保费;若实际执行中扫描开销明显失控,再评估分档(快扫集/全集),不预先开口子。
