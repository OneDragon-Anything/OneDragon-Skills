# ADR-0003:结构性约束优先于自觉(本 skill 的元决策)

- Status: accepted
- Date: 2026-08-25

## Context

多条纪律(收账即补位/亲验/泛化排查/校准资产)都曾以「口头纪律」形态存在过并失效过:长会话注意力衰减下,写在入口文件的纪律会在当前最显眼的刺激(在飞件/最新日志行)面前失重。实证多次:并行度纪律成文仍空转、模拟先行成文仍默认上实机。

## Considered Options

- **更严格的口头纪律(措辞加粗/置顶)**:否决——同等失效,只是更醒目地被忽略。
- **全靠自动化 hook**:否决过度——并非所有纪律可 hook 化(如「对照权威文档」是判断类);且 hook 建设成本高,留给确实可代码化的检查。
- **结构性约束分层落位(选中)**:能变机制的变机制(清单格式/锁/提醒角色/代码化检查),不能变的留判据+退化信号自查(§7)。

## Decision

本 skill 全文按「结构性约束>自觉」组织:每个纪律条目回答「它靠什么机制维持」——格式约束(四来源/辩护带清单)/时间约束(提醒角色)/代码约束(锁/检查器)/可证伪信号(连续同答/产出密度)。纯自觉条款不收录。

## Consequences

- 正:纪律的失效不再静默(格式不对=看得见;锁红=测试失败)。
- 负:机制建设成本前置(每个纪律要想落位);某些判断类纪律只能弱约束(退化信号自查兜底)。
