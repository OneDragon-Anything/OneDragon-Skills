# od-dev-agent-autonomous-mode · design overview

## 定位

用户授权 agent 长时间自主决策推进(不逐项确认,直到叫停)时的**运转框架**:开启仪式、指挥官-worker 编排、三纪律(派发/审查/治本)、资产组、提醒网、早停与防退化。跨领域通用(任何项目/玩法);领域操作细节归各领域 skill(如货币战争的 sr-od-currency-war-dev)。

## 目标

1. 把「自主推进」从口头授权变成可冷启动复现的流程(新会话读 skill 即获得完整启动能力);
2. 用结构性约束替代自觉(长会话注意力衰减下,凡靠「记得」的纪律都会失效);
3. 防四类实证过的退化:确认循环/认知窄化/rubber-stamp/目标漂移。

## 边界

- **不管领域操作**(怎么建档/怎么写 op/怎么判读——归领域 skill 与项目 docs);
- **不管单人单任务**(没有多轮自主推进的,普通流程即可);
- **不管 goal 类工具的取舍细节**(只给「事件驱动优先,定时轮降级为心跳」的原则;工具有无随环境);
- **不绑具体提醒工具**(schedule/定时器/任何会话级提醒机制,按环境取用)。

## 构成(SKILL.md 章节映射)

| § | 关注点 |
|---|---|
| checklist | 开启 6 步(完成门) |
| 1 | 冷启动序(三源对齐+三件套) |
| 2 | 指挥官-worker 编排(额度/派单三带/保留件) |
| 3 | 三纪律(派发四来源/审查亲验分层/治本四判) |
| 4 | 资产组+分层落位三问 |
| 5 | 提醒网角色集(自执行 vs 派 agent)+提醒词写法(用户可见的持久化文本)+长任务自校准 |
| 6 | 早停与收口 |
| 7 | 防退化自检表 |

## 内容依据类型

**方法论覆盖型 + 纠正型混合**:编排/资产/提醒骨架来自实战提炼的方法论(覆盖型);四来源盘点/辩护带清单/双窗确认等条款来自实证失败模式的纠正(纠正型,判例归消费方本地反馈队列,skill 只留形态与自救——见规范 4)。
