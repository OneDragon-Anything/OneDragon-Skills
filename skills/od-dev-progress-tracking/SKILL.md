# 进度记录与防偏离(任务树状态机)

**全局方法**(不绑具体项目/玩法/框架)。适用于任何复杂多步骤开发。各工件 skill 在各自 SKILL.md 末尾有「进度模板」小节提供叶子完成判据;本 skill 只组织成树(状态机 + 聚合 + 防偏离),不发明判据。具体应用的阶段骨架(如 gameplay-automation 的 5 阶段)在对应流程 skill 的 reference 里。

---

# 总纲(通用机制,递归不变量)

> 适用于树的**每一层**:根/阶段/工件/子项/叶子都是任务节点,有状态、可聚合、可加子任务、可改状态。

## 1. 原则

- **状态机,不是叙事**:节点状态可更新,不 append 过程。过程时序/决策 why/历史各有归属。
- **扎根 skill,不双源**:节点只存「状态 + 判据指针」,判据原文在对应 skill 模版(§10),不复制。
- **每层有索引**:每目录 `进度.md` = 该层目标 + 子任务表(编号/状态/依赖/卡点)+ 当前焦点。

## 2. 任务树(递归)+ 文件组织

**树形**:`app(根) → 阶段 → 工件 → 子项 → … → 叶子`,**任意深度**递归。
- **递归终止判据**:节点能**独立完成 + 独立验证**(单画面单子态建档过 / 单 op `run_operation` 过 / 一段流程端到端过 / 一类数据采集完)。能 → 叶子;含多个工件或多判据 → 继续拆子节点。
- **编号**(层级,反映深度):`4.2.1.3` = 阶段.工件.子项.更细。中途插入用尾缀(`4.2.1a`)。
- **聚合**:父节点状态 = 子节点按 §4 派生(无自由度)。

**文件/目录组织**(任务树落盘,示例):
```
<app>_dev/
  进度.md                          # 根索引:app目标 + 阶段状态(聚合) + 当前焦点 + 防偏离门 + 权威源映射表 + 阈值实例
  1_<阶段>/进度.md                  # 阶段索引(子任务表 + 焦点)
  ...
  N_<阶段>/
     进度.md                       # 阶段索引
     <工件>/进度.md                 # 工件节点:子任务表 + 判据指针
     <工件>/<子项>/进度.md          # 更深层(如需要)
  events.md                        # 分支长尾收件箱(§11)
```
- 每层一目录 + `进度.md`(索引);叶子判据状态写在所在层 `进度.md` 的子任务表。
- `events.md` / 决策日志 / 过程时序记录 / doc 各归各处(§9 边界)。

## 3. 状态机(文本可 grep)

| 状态词 | 语义 | 适用层级 | 格内容 |
|---|---|---|---|
| 已过 | 过(满足判据) | 节点级 | `已过 D-NN` |
| 未做 | 未做 | 节点级 | `未做`(回退见下) |
| 进行中 | 已动手未闭环 | 节点级 | `进行中`(可选注在做啥) |
| 锁定 | 前置节点未过,禁止推进 | 节点级 | `锁定 前置=<节点号>` |
| 不适用 | 不适用 | 节点级 | `不适用 <为何>` |
| 部分过 | 子节点部分过(聚合态) | 父节点级 | `部分过 <缺什么>` |
| 罕见态 | 罕见子态特例(走不完验证) | 子态节点特例 | `罕见态`(见 §11) |

> 决策日志用项目自选编号(示例 `D-NN`)。

**聚合用二分**(§4):「满足」= 已过 / 不适用 / 罕见态(声明 fallback);「未满足」= 未做 / 进行中 / 锁定。

**回退标记**(非独立状态,跟「未做」后):`未做 曾过D-XX 回退D-YY`。仅用于「误判回退」(原判断错);「代码退步」(改坏致退步,原判断当时对)记新 `未做` + 新决策,不用回退。

## 4. 聚合规则(父 = 子派生,按序匹配,无自由度)

| 序 | 子节点情况 | 父节点状态 |
|---|---|---|
| 1 | 全部满足(已过/不适用/罕见态) | 已过 |
| 2 | 全未满足,且全锁定 | 锁定 |
| 3 | 全未满足,有未做(无进行中) | 未做 |
| 4 | 有满足 + 有未满足,满足数 **>** 未满足数 | 部分过 |
| 5 | 其余(有进行中,或 满足数 **≤** 未满足数) | 进行中 |

- 按序匹配,先命中先生效(序 2/3 在序 4/5 前,消除"全未做"歧义)。
- 计数:满足数 vs 未满足数直接比较(**不适用计入满足数**)。边界:满足数 = 未满足数 → 序 5(进行中,未过半)。
- 罕见态子节点 = 满足侧(不阻塞父聚合);其自身晋升见 §11。
- **锁定传播**:前置未过 → 依赖节点标「锁定」。依赖须 DAG(有向无环);出现环 = 建依赖时出错,拆环。改一处叶子 → 沿依赖链向上重算各层聚合。

## 5. 中途加任务(树操作)

- 发现新工件/新子项/新事件/新数据类 → **按对应 skill 规范建新节点**,挂进对应阶段。
- 编号接续(§2);依赖连相关节点;状态=`未做`;判据指针指向 §10 skill 模版;记「为何加」(来源:实机撞到/版本更新/拆分)。
- **拆文件判据**:单节点子项 > ~20 或流转成非平凡图(循环/多对多)→ 拆子目录(任务树下=子节点各一进度行)。

## 6. 改状态(树操作)

- **推进**:未做 → 进行中 → 已过(格内容记 `已过 D-NN`,why 留决策日志)。
- **回退**:已过 → 未做(标 `回退 D-YY` 误判 / 新决策 代码退步)。假绿复核反转(原判不适用实际要认全)→ 闭环回退为未闭环 + 补建全集,记决策。
- **唯一真相 + 索引同步**:状态改在节点;层级索引按 §4 聚合派生回填(沿依赖链重算)。

## 7. 继续之前任务(跨会话/loop 续)

- **根索引顶部**永远有「当前焦点」(哪个阶段/哪个节点/卡什么)+ 「下一步」。每层索引有「该层焦点」,层层下钻到正在做的叶子。
- **恢复流程**:读根索引 → 按焦点下钻 → 看卡点+依赖 → 继续。焦点定位不上 → 偏离信号,回最近未闭环叶子。

## 8. 防偏离门(loop 每轮必过)

> 本方法补充,非 playbook 原文。防止自主 loop/agent 漂离主线。

- **定位五元组(硬门,必填)**:焦点必填 `阶段X / 节点Y(工件) / 子项Z / 判据N / 本轮动作W`。
  - **判据 N**:填 §10 对应 skill 模版的完成判据(或项目自定义判据)。
  - 填不出 = 偏离信号,回最近未闭环叶子。
- **产物落点校验(硬门,git diff 机械校验)**:工件节点的子任务改动**不得触碰项目定义的核心模块**(如策略行为模块:评分/权重/搜索/选择;具体路径由项目在根索引/CLAU.md 列出)。触碰 → 属核心模块改动,得过下面核心锁。**局内状态对象字段定义不算**(实例须在根索引列出本项目具体算/不算的核心模块路径)。
- **核心模块锁**(改核心模块先过三解锁):
  - (解锁一·半硬)**改动读取的每个「从权威源读取的字段」,其权威源的对应子任务全已过**。**非权威源读取字段(代码内部派生值)豁免**。字段→权威源映射**必须记入决策日志(D-NN)供复核**。
  - (解锁二·硬)端到端跑通有观测回路;(解锁三·硬)客观指标已定义。
  - **权威源**:该信息最完整/最准的来源,登记在**根索引的映射表**。
- **跨阶段不变量自检(软门)**:①结论跨多样本?②动手前查文档非凭猜?③先读日志?④卡住时分清技术故障 vs 认知缺口?任一不过=偏离。致判据变化→决策日志;未致→过程时序记录。
- **进行中工件节点≤1(软门)**:同时「进行中」的**工件级**节点 ≤ 1。开新工件先闭环当前或显式暂停记决策。

## 9. 边界(判据不双源)

| 信息 | 归属 | 进度节点 |
|---|---|---|
| 完成判据/模版原文 | 对应 skill 模版(§10) | 只存「判据指针」 |
| 画面/工件事实 | 项目 doc(screen doc / design doc) | 引用 |
| **状态流转 / 要读信息清单** | 项目 doc | 工件节点存指针 |
| **权威源映射** | 根索引 | 工件节点存指针 |
| 代码行为/当前值 | 代码 | 不记 |
| 状态变化 why/偏离致判据变化 | 决策日志(D-NN) | 节点标 `已过 D-NN`/`回退 D-YY` |
| 过程时序 | 过程时序记录(项目自选) | 不记 |
| 分支长尾(新事件) | events.md(§11) | 节点用指针 |
| **任务完成状态+依赖+卡点** | **进度树(本方法)** | **唯一归属** |

# 10. 叶子任务类型 → skill 模版映射(落实 skill)

> 进度方法论**不发明判据,只组织各 skill 的模版成任务树**。叶子任务类型对应一个 skill 提供的完成模版(判据/结构),节点「判据指针」指向它。
> 各工件 skill 在各自 SKILL.md 末尾有「进度模板」小节,记录它负责叶子的完成判据 + 防跑偏点。本表是总览指针,详细完成判据在各 skill。

| 叶子任务类型 | skill 模版 | 该 skill 提供的完成判据 |
|---|---|---|
| 画面建档(初步/完整) | od-dev-screen-onboarding | analyze+视觉大模型+doc+核实area+归档fixture |
| operation 编写/调试 | od-dev-write-operation | 节点图+round结果+探索式主线 |
| run_op 实测 | od-dev-write-operation(run_op 微循环) | 单 op `run_operation` 实测过 |
| 代码测试(fixture/unit) | od-dev-write-operation/references/testing | fixture+unit 测试过 |
| 分支覆盖 | 对应流程 skill + 本方法 §11 | 主分支覆盖 + 连续 M 次无新分支 |
| UI 区域坐标检测 | od-dev-ui-region-detect | 稀疏独特→VLM/密集网格→CV投影 |
| app 编排/factory/config/GUI | od-dev-write-application | Application=Operation + factory注册 |
| 端到端验证/测试/成文 | 对应流程 skill | run_standalone_app跑通+ruff+测试仓+docs |
| **罕见态** | **进度方法自身**(不指 skill) | 声明 fallback + events 条目 |

> 各项目/玩法可能有额外的叶子类型(如策略迭代、数据采集)—— 在对应流程 skill 的 reference 里定义。

# 11. 事件长尾(events.md)

运行中持续冒出的新分支/新画面/新事件收件箱。分节:主收件箱 / 广义降级区(可复现待排期)/ 已知局限暂搁。
- 条目:`类型/归属工件/fixture/代码测试/来源(建档已知/运行时新发现)/状态`。
- **降级流转**:条目停留超**降级阈值**未三过 → 按可否复现移入广义降级区。暂搁条目停留超**最终阈值**仍未复现 → 决策日志记「已知局限」+ events 标最终态。
- **清理(正常分支)**:handler+fixture+测试**三过** → 补齐子任务迁入工件子节点 → events 删条目。
- **清理(罕见态特殊路径)**:判据表罕见子态行保持 `罕见态`(**不晋升**);events 留广义降级区靠运行时撞;撞到且能完整验证 → 该子态从 `罕见态` 变全已过(晋升)+ events 删。
- **全新独立工件晋升**:先建工件节点(子任务骨架)→ 走子任务 → events 删条目。
- **退出判据**:连续 N 次运行无新 event 涌入。阈值(M/N/降级/最终)按项目单局规模定,实例在根索引给出。
