# ADR-0003:DAG 事件流账本替代 Markdown 行文法账本

- Status: accepted
- Date: 2026-09-06
- Supersedes: 0002 的行文法部分(两级平铺、模块目录、七词状态机、progress.py write/check);0002 的分解树与依赖网分离、机械聚合、流水独立三原则延续。0001 入口定位层思想延续(入口.md=目标+判据指针)。

## Context

行文法账本(ADR-0002)实战三周(2026-08-31 CW 迭代全程),暴露的结构病:

1. **依赖边不可算**:「前置=」是括号内自由文本,实证账本中 21 个活任务的前置引用没有一条机器可解析(「前置=证明件过」「前置=54行5轮清洁攻击达成」);「锁定」是否该解锁只能靠人肉追踪,实证存在锁定行积压脱离追踪。
2. **双源断裂**:账本(状态)+流水(变更史)两条写入路径,直改账本忘补流水=审计链断。
3. **读-改-写更新**一行与并发写天然冲突(靠单写者纪律兜)。
4. **历史与活态同文件**:300+ 行账本约九成为已过死节点,检索靠 grep 过滤、人读靠肉眼跳。

2026-09-06 迁移实证(旧账活任务迁入新模型)进一步暴露行文法的隐藏代价:被 ≥5 个任务依赖的关键任务(「P1 设计批」)**从未在账本登记**——幽灵前置藏于自由文本无人可见;「部分过」聚合态、「任务的内部里程碑前置」均无法被新模型表达,倒逼显式化(拆任务)。

## Considered Options

- **行文法改良**(全局任务 ID+graph 子命令+引用校验):否——正则解析天花板仍在,引用/字段歧义只是被收窄;用户裁决不考虑旧格式兼容,无包袱可背。
- **SQLite 正本**:否——查询强,但二进制损坏不可人工修复;agent 的文本工具(grep/read)不能直读。
- **单文件 YAML/JSON 状态正本**:否——中间插行脆弱,读-改-写并发冲突,变更史仍需第二文件承载(双源病不治)。
- **JSONL 事件流(纯 append)+ 折叠现算状态**:选——append 行级原子;agent 原生可读;坏一行丢一行不炸全库;加字段向后兼容;变更史=正本本身。

## Decision

1. **正本 = 事件流 JSONL**,四种事件(add/status/note/dep),纯追加;当前状态=脚本折叠现算,不落盘。status 事件自带 from,重放可检测乱序/冲突。
2. **节点 = DAG 顶点**:id/title/module(封闭枚举:流程|决策|支撑)/status(五态:todo|doing|wait|done|dead)/deps(单侧存边,反向现算)/cond(图外等待,不进图)/criteria(凭据指针,追加式)/assignee+since(doing 必带,恢复锚点+挂了检测)/dead_reason/notes。
3. **流转矩阵写入校验**:被挡不占状态(可派=todo+图算);dead 终态无出边(dead 视为依赖已满足,复活会炸图);done→todo 回退必带 why 且下游自动回被挡;允许跳步(防假完成靠 criteria 必带)。
4. **图运算现算不落盘**:ready/blocked/dependents/拓扑/环;环在写入时拒绝,不做事后体检。
5. **三条建模纪律**(迁移实证倒逼):幽灵前置禁令(deps 引用必须存在,多任务共等的不存在行必须立项);里程碑显式化(deps 只认 done,任务的中间状态拆独立任务);cond 禁写任务 id(该建边)。
6. **单写者纪律延续**(子 agent 汇报、编排者记账),写安全靠纪律+纯追加,不加锁。

## Consequences

- 正:「忘记解锁」类状态腐化被机制消灭;审计链=正本;并发写安全;活图恒小(终态不入 ready/list 视图);派单就绪集机械可得;派单上下文自包含(card)。
- 负:①无聚合 summary 命令(module 级汇总待有需求再定);②「部分过」取消——多子步任务须拆链或 doing+note,粒度管理责任上移到建模时;③「进行中」模型假设单执行者,周期性活动(如持续对抗循环)记 assignee=编排者是近似;④行号引用全部失效——旧账引用只能以「源=<旧账路径:行号>」形式存于 note;⑤两处跨 skill 文档(od-dev-gameplay-automation 的 references/progress-tracking.md)仍描述行文法,待适配。
- 复活条件:事件流文件膨胀失控(单迭代事件数使折叠变慢)→ 加 compact(终态折叠归档);本设计事件量级(数百)远未触及。

## 修订(2026-09-06,用户裁定)

- **撤除叙事流水层**:journal 命令不建,`流水-*.jsonl` 文件约定废除;叙事内容(判读/验收经过/事故复盘)住**产物文档**(报告/复盘 doc),账本只经 criteria/note 存指针。0003 延续 0002 的「流水独立」原则据此作废;旧 progress.py journal 因依赖旧目录结构(祖先找 进度.md)对新迭代天然失效,无保留价值。
- **撤除入口.md**:迭代目标单一源=项目指令文件「目标」字段(always-on 在场);判据单一源=skill 模版与玩法文档——入口.md 是第二份抄本(必漂移)。「入口定位层」(ADR-0001)由指令文件常驻 + 盘点任务书显式抄送目标取代;init 子命令随之撤除(目录随首条 add 自动建)。迭代目录仅 dag.jsonl 一个文件。
