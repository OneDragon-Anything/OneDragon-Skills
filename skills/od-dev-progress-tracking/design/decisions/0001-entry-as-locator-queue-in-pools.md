# ADR-0001:进度文件收敛为定位层,队列与状态全归三池(重整起号)

- Status: accepted
- Date: 2026-08-27

## Context

本 skill 的 ADR 曾于 2026-08-27 大重整前积累 11 条,重整中再演进入口形态三连改(三小节→四块→定位层),同日多次决策互相覆盖,历史 ADR 已不可信(用户定调:旧的都删,重整起号)。本 ADR 为新 0001,记录重整后的最终形态与全部演化决策;早期 ADR 0001-0011 已删,其仍有效的结论被本条吸收。

## 重整决策全景(演化顺序)

1. **入口三小节时代(至 2026-08-27 晨)**:迭代入口=工作状态(主线任务/周期改进/持续运行)+涉及 app 表+并行协议脚注。三小节设计于提醒网缺位时代——用文档在场替代机制缺位。实证病:入口 55→126 行回弹三次(收账叙事、按 commit 补记、逐局结论摘要),全靠人工清理;周期改进/持续运行两节长期停更成死账。
2. **提醒网接管(ADR-0011 承前)**:提醒网消息自包含重建后,周期改进由派发盘点+回顾承载,持续运行由值守+领域监控承载,不再进进度文件;健康对照数字(测试条数/语料量)不落文件——随时可重新观测的事实,查一下比记的准。
3. **队列归池行**:入口的「主线状态」(在飞/下一个待派/挂账表/候用户)与三池行重复——在飞状态池行本来就有(进行中);挂账=池行「待激活 条件=…」;候用户=池行「锁定 前置=用户裁决」。入口承担这些职能是池行字段没写全逼出来的重复记账,信息流向无结构约束的自由文本容器=流水账的机制根源。
4. **「下一个待派」指针废除**:派单不是高频决策(一单几十分钟,盘点 15 分钟一轮),每轮重扫全树综合判断不是浪费是应该——上轮排序依据的局面早已变化,旧指针=过期判断;且指针会被当承诺执行,「守既定安排不再重新想」正是自主推进空转病灶之一。
5. **当期目标行废除**:入口曾抄 AGENTS.local 目标行+判据括号=第三份抄本。判读标尺的家在 research(判据定义),判读什么由判读四问提醒钉住,方向由 AGENTS.local 目标行永远在场承载。「判据状态由判读评估,不随任务完成自动翻转」的判据保留(进判读纪律)。

## Decision

- **迭代入口 = 定位层,两件**:目标一行(从指令文件抄最终目标,保进度树自含——任何入口摸到树第一行知道在追什么)+ 涉及 app 表(树下 app 子目录指针,多 app 迭代的地图)。不再有工作状态/队列/挂账/候用户/结论锚/判读锚点任何自由内容节。
- **队列与状态全归三池行**:任务+状态词+待激活条件/锁定前置字段写全;恢复=状态词 grep 全树(§7 不变)。
- **派单=盘点轮每轮重扫全树综合判断**(事件驱动的"完成一件立即取下一件"同样=扫树挑,非读指针)。
- 结论锚删:被消费的结论已是池行任务,没消费的等盘点发散扫报告;判读锚点=一局生命周期的临时物,活在判读提醒轮的现场,不落文件。

## Consequences

- 正:每份信息单一归属(入口=定位,池=任务状态,AGENTS.local=方向,research=判据,提醒网=判读与盘点机制);入口形态瘦到无法膨胀(两节,无自由文本区);流水账的结构根源(信息流向无约束容器)消除。
- 负:入口不再提供队列总览,跨会话恢复多一步(grep 三池);结论速查需去 ADR(盘点发散来源覆盖)。接受。
