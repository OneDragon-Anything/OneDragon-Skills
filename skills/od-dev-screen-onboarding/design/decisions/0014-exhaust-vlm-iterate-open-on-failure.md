# 0014. 穷尽视觉大模型:交互无效时叠加失败迭代提问,穷尽前不放弃

- **Status**: accepted
- **Date**: 2026-08-07

## Context

§2「探索未知画面」已立「开放式提问 + 三工具交叉 + 穷尽自查」,但**没说「视觉大模型给的交互方式试了无效,该怎么办」**。常见失败:视觉大模型给出的第一种交互方式试了无效 → agent 判定「视觉大模型没用 / 走不通」→ 放弃视觉大模型,转去瞎猜坐标 / 干卡 / 过早问用户。实际上视觉大模型可能还有第 2、3 种交互方式没问到(单次开放式提问受显著性驱动会漏 + 诱导式问法压制输出,见 ADR-0009)。

根因:**视觉大模型是唯一能真正「看懂」画面的途径** —— OCR 看不见图形 / 图标 / 布局 / 状态;点击只验证已知坐标、不能发现新交互。放弃视觉大模型前不穷尽它 = 浪费唯一可靠的画面认知源。

用户原话点出态度:「视觉大模型是唯一能真正看懂图的途径,一定要努力到无能为力才可以放弃,甚至有不能放弃的感觉,还是应该接」—— 理性落地 = **有明确判据的穷尽**(给不出新交互方式才算穷尽,可转),非无限执念。

## Decision Drivers

- **视觉大模型不可替代**:看懂画面的唯一途径(OCR / 点击各有盲区)→ 认知未知画面时是主线,穷尽前不放弃。
- **单次开放式提问会漏**(显著性驱动 + 诱导式问法压制)→ 要**迭代**(叠加失败继续问)才补全,一次问完就停 = 没穷尽。
- **过早放弃的后果**:转瞎猜 / 干卡(违反 ADR-0012 禁干卡)/ 过早问用户 —— 都比「多迭代几轮提问」差。

## Considered Options

1. **叠加失败迭代提问,穷尽视觉大模型(本决策)**:交互无效 → 在原提问上叠加「刚试了 X 没用,还有别的交互方式吗?」继续问,反复到视觉大模型给不出新方式。
2. **问一次视觉大模型,试无效就放弃**:否 —— 浪费唯一看懂图途径;单次开放式提问会漏,迭代才补全。
3. **诱导式 / 窄问**(「X 按钮在哪?」):否 —— 压制输出,漏掉没问到的交互方式(ADR-0009 第 1 点「开放式提问优先」的根因)。
4. **永不放弃视觉大模型**(无限迭代):否 —— 要有判据「给不出新方式 = 穷尽」,否则无限循环白耗。用户「不能放弃的感觉」理性上「还是应该接」= 接受**有判据的穷尽**,非无限执念。

## Decision

§2「探索未知画面」加第 4 点:

- **核心认知**:视觉大模型是唯一能真正看懂画面的途径(OCR 看不见图形 / 图标 / 布局 / 状态;点击只验证已知坐标)→ 认知未知画面时是不轻易放弃的主线。
- **操作**:视觉大模型给的交互方式试了**无效 ≠ 视觉大模型走不通** —— 在原提问上**叠加失败继续问**(「刚试了点 A / 按 B 没反应,还有别的交互方式吗?」),反复叠加。
- **判据(什么时候才算穷尽)**:视觉大模型**还能说出新的可交互方式** → 没穷尽,继续;**反复问只重复已试过的方式 / 说「没了」** → 才算穷尽,转 OCR / 点击 / 问用户。
- 态度:努力到这个判据才放弃视觉大模型 —— 穷尽前放弃 = 浪费唯一可靠认知源。

**不进 skill 的**:迭代提问的具体措辞(项目 / 画面而异,判据级够);最多迭代几轮(无硬上限,以「给不出新方式」判据收敛,非次数封顶)。

## Consequences

- **正向**:穷尽唯一看懂图途径 → 少瞎猜 / 少干卡 / 少过早问用户;未知画面认知更完整。
- **代价**:迭代提问多轮,耗 token + 时间(但比「放弃后瞎猜 / 干卡 / 反复问用户」省)。
- **边界**:判据明确(给不出新方式 = 穷尽),非无限循环;**视觉大模型状态推理不可信依旧成立**(§2)—— 迭代提问问的是「客观有哪些可交互方式」,不是「判断状态 / 作用」(那要点击验证)。
- **推翻它会碎什么**:删迭代穷尽 → 一次无效就放弃视觉大模型 → 转瞎猜 / 干卡 / 过早求助;唯一看懂图途径被浪费。
