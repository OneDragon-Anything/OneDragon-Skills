# 0013. 认知层穷尽探查画面所有可交互元素 + 探查顺序(不可逆出口最后)

- **Status**: accepted
- **Date**: 2026-08-07

## Context

常规建档流程(§1 analyze → §2 视觉大模型 → §3 建档 → §4 缺口 → §5 建模)**没有一步强制「穷尽探查画面所有可交互元素」**。「全部可交互元素 + 各自点后跳哪」只作**目标判据**(建档 / 快修判据)和**卡住时的强制补救**(ADR-0012 卡住画面协议第 3 步)出现。正常建档时,凑「可交互元素清单」靠 §2 视觉大模型开放式枚举 —— 但 §2 自己承认**视觉大模型 单看会漏**(漏非显眼区域 / 小元素 / 非文本状态)。于是:

> 视觉大模型 漏元素 → §4 缺口分析对照的清单不全 → 建档漏 → 写出来的 op 只覆盖认知到的元素 → 运行时撞到没认知的元素又卡(掉回卡住画面协议)。

这正是「凭猜改 → 只覆盖一种情况、漏另一种 → 回归」的典型。

进一步:就算决定逐个交互探查,若**从上到下无序点**,可能第一下就点掉「下一步 / 开始」这类**不可逆出口**,离开画面 —— 没探完的元素再也探不到,认知停在半截。

## Decision Drivers

- **建档完整性**:认知漏元素 → op 覆盖不全 → 运行时卡;建档阶段就该把认知补全(理解画面全貌),不是等运行时撞了再补。
- **探查顺序影响能否探完**:点错不可逆出口离开 = 探查中途断,认知停在半截。
- **两层区分(防误读)**:认知层(理解,该穷尽)vs 建模层(§3.5 AREA 增量,用到才建 area)是两回事 —— §3.5「AREA 别堆全」只约束建模,不该被误读成「认知也不用全探」。

## Considered Options

1. **认知层穷尽探查(本决策)** vs 只靠 §2 视觉大模型 枚举 / 按需探不强制:
   - 只靠视觉大模型:否决(视觉大模型 会漏,清单不全)。
   - 按需探不强制:否决 —— 认知不全 → op 不全 → 运行时卡,违反「凭猜改只覆盖一种情况」。建档阶段补全认知比运行时撞了再回来补高效。

2. **探查顺序:不可逆出口最后 + 结合本画面判断(本决策)** vs 备选:
   - 机械规则「所有推进按钮 /『下一步』最后」:否决 —— 要**结合具体场景判断**。子菜单离开能返回、副本「开始」进战斗不可逆,不是所有「离开画面」都不可逆;一刀切会把可早探的可逆出口也拖到最后,白费轮次。
   - 无序从上到下探:否决 —— 可能第一下点掉不可逆出口离开,探查中断。

## Decision

两条进 SKILL.md(指令式 + 判据,非具体游戏例子):

- **§4 缺口分析**:「可交互元素」清单要**穷尽**,别只靠 §2 视觉大模型 枚举(会漏);交叉补全 = §1 全量 OCR + 信息源三层(screen_info `area_list` 全集 + 代码 `@operation_node` 链);每个元素还要知**行为(点后跳哪 / 干嘛)**,光认名字不够;目标 = 建档 / 快修判据「全部可交互元素 + 各自点后跳哪」。逐个交互验证行为时守探查顺序。
- **卡住协议第 3 步**:探查顺序 = **不可逆出口最后**(凡逐个交互探查都守,不只卡住协议)。先探留在当前画面的(展开 / 选中 / 切 tab / 开子面板),离开画面的出口留最后;尤其离开后回不来的(进战斗 / 开始挑战 / 确认推进 / 传送 / 消耗类出口)。**结合本画面判断哪些是「回不来」的出口**(判据:这交互离开后还能回到当前画面继续探查吗?能 → 早探;不能 / 不确定 → 最后探,甚至先不交互靠代码补认知)。

**两层区分(显式)**:认知层穷尽探查(理解画面,**不等于**建 area);建模层 AREA 增量(§3.5,用到才建)。补认知 ≠ 堆 area。

**不进 skill 的(归项目 doc / 代码)**:本游戏哪些按钮是不可逆出口(项目 doc 记);逐个交互的具体坐标 / sleep(代码 / 既有操作时序节)。

## Consequences

- **正向**:建档认知完整 → op 覆盖全 → 少运行时撞未认知元素(少掉回卡住协议);探查不被「点错出口离开」中断;§3.5「AREA 增量」与「认知穷尽」分清,不再被误读冲突。
- **代价**:逐个交互探查成本高(元素多时);边界 —— 不确定的不可逆出口可先不交互,靠代码 / 别的途径补该元素认知(认知层穷尽不等于硬把每个元素都点一遍)。
- **推翻它会碎什么**:删穷尽 → 认知漏 → op 不全 → 运行时卡;删顺序 → 点错不可逆出口离开 → 探查中断、认知停半截。
