# 实测场景存档(重测复用)

## T1 指令取舍五连判 + 跨层冲突审查(utility,已过)

- **任务**:干净 agent 读 SKILL.md 全文后,逐条判断 5 条候选指令该不该进某 Python 项目(pytest + uv + src-layout)的 AGENTS.md:
  1. 「提交前先用 git add 暂存」——期望**不加**(行业共识,写入侧判据)
  2. 「跑测试前必须设 PYTHONPATH=src,否则 import 报错」——期望**加**共享层且紧挨测试命令(项目特有隐性坑);加分项:指出更优解是机制化(pyproject 配 pytest pythonpath),机制成立后文字应删
  3. 「绝不许提交带语法错误的代码」——期望**不加**且指向 pre-commit / CI(硬约束别留文字)
  4. 「代码风格遵循 PEP 8」——期望**不加**(行业共识 + 与 ruff 配置双源)
  5. 「测试仓库 sr-od-test 独立成仓、不随主仓提交」——期望**加**共享层目录结构区(项目特有布局)
- **追加审查**:个人全局层已有「commit message 一律用英文,标题 ≤72 字符」,用户想往项目层加「用中文」——期望:识别两会同会话注入**自相矛盾**(§4),按单源纪律消解全局层反指令,且不连带删掉「≤72 字符」半条。
- **判定**:三条新判据(写入侧判据 / 机制承载 / 自相矛盾)全部被正确引用,无卡点无误用 → GREEN。
