# OneDragon-Skills

OneDragon(一条龙)系列游戏自动化项目(StarRailOneDragon / ZenlessZoneZero-OneDragon / …)的**公共开发 skill 仓库**。系列项目共用同一套框架(`one_dragon` 公共包)与开发方法论,开发类 skill 在此统一维护,各项目引用同一套。

## 使用

- 安装:`npx skills add OneDragon-Anything/OneDragon-Skills`(agent-skills 开放标准 CLI,支持 Claude Code / Codex / Cursor 等 70+ agent;手动挂载另见 [docs/setup/ai_coding.md](docs/setup/ai_coding.md))
- skill 索引与用途:[skills/README.md](skills/README.md)

## 开发 / 维护

- 约定入口:[AGENTS.md](AGENTS.md)(命名 / 结构 / 硬规范 / 流程)
- skill 写作细则:`od-dev-writing-skills` skill
